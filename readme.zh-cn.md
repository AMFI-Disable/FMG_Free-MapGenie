# FMG 地图扩展

[English](readme.md) · [参与贡献](contributing.zh-cn.md) · [上游项目](https://github.com/V1P3R-FMG/free-map-genie) · [更新日志](changelog.md) · [安全政策](security.md) · [MIT 许可证](license)

本仓库是社区地图扩展的个人分支。第三版仍在开发中，使用 WXT、TypeScript、React 和 Dexie。地图记录保存在浏览器本地，旧版与新版的数据结构不同。切换版本或浏览器配置前，请保留现有地图笔记的备份。

## 代码与反馈

第三版代码位于 `src/`，浏览器端测试位于 `e2e/`，仓库根目录还保留旧版实现。反馈地图显示或笔记问题时，请说明浏览器、扩展版本、复现步骤和数据是否来自旧版本。不要在公开报告中附上身份令牌、账号信息或私人地图笔记。

请在你有权访问的地图和数据范围内使用工具。订阅、权限与官方同步功能以地图服务提供方的授权为准。[本分支星标历史](https://www.star-history.com/?repos=AMFI-Disable%2FFMG_Free-MapGenie&type=date)
